# Arduino Mega Password-Protected Lightning Stairs System

A smart staircase lighting system using Arduino Mega, IR sensors, keypad authentication, LCD display, and servo-controlled gate.

## Features

- Password-protected access using 4x4 keypad
- Sequential stair lighting using IR sensors
- Servo-controlled gate operation
- LCD status display
- Automatic light timeout

## Components

- Arduino Mega 2560
- 16x2 I2C LCD
- 4x4 Keypad
- Servo Motor
- 5 IR Sensors
- LED Strips / LEDs
